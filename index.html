Core Concept

What is Cloud Computing?

An overview of cloud infrastructure, elasticity, and shared resource paradigms.

Requirement Met: 92 Words (Exceeds 80-word minimum)

Cloud computing is the on-demand delivery of computing services over the internet, including server infrastructure, data storage, databases, networking, artificial intelligence, and software analytics. Instead of purchasing, maintaining, and operating physical on-premises servers and hard drives, organizations and developers can lease flexible virtual resources directly from major cloud service providers such as Amazon Web Services, Microsoft Azure, and Google Cloud Platform. This computing paradigm provides tremendous advantages, including rapid scalability, elastic resource provisioning, high fault tolerance, and a cost-effective pay-as-you-go financial model that eliminates large upfront capital expenditures.

Pay-as-you-go

Convert hefty capital expenditures (CapEx) into predictable operational expenses (OpEx) by paying only for consumed compute time and bandwidth.

Rapid Elasticity

Dynamically scale computational workloads up or down automatically in response to real-time incoming visitor traffic fluctuations.

Global Availability

Deploy applications across worldwide Content Delivery Networks (CDNs) and multi-region data centers with minimal latency and high resilience.

Built-in Security

Benefit from world-class enterprise physical security, continuous TLS encryption, automated patching, and robust compliance certifications.

Service Models

Cloud Service Models

Understanding the SPI classification model: Infrastructure, Platform, and Software as a Service.

Infrastructure Layer

IaaS

Infrastructure as a Service

IaaS provides raw, foundational computing infrastructure over the cloud, including virtualized physical servers, block storage, and software-defined networking. The cloud vendor owns and maintains physical data center facilities, while the tenant assumes full responsibility for configuring and managing operating systems, middleware, runtimes, and application code.

Key Management Scope:
  • You manage: OS, Runtimes, Apps, Data
  • Provider manages: Physical servers, Virtualization
Real-world Example: Amazon EC2 (Elastic Compute Cloud), Microsoft Azure VMs, Google Compute Engine.
Platform Layer

PaaS

Platform as a Service

PaaS provides an optimized cloud application development and deployment environment. The cloud provider abstracts away physical hardware, operating systems, security patches, container runtimes, and database engines. Developers can focus entirely on writing business logic and pushing code without worrying about server provisioning or OS configuration.

Key Management Scope:
  • You manage: Application source code & Data
  • Provider manages: OS, Runtimes, Servers, Network
Real-world Example: AWS Elastic Beanstalk, Heroku, Google App Engine, Render.
Software Layer

SaaS

Software as a Service

SaaS delivers ready-to-use, end-user applications accessed directly through modern web browsers or native mobile interfaces. The provider owns and operates the entire application lifecycle, including infrastructure maintenance, load balancing, continuous feature upgrades, and database integrity. The user simply consumes the software.

Key Management Scope:
  • You manage: User settings & Profile data
  • Provider manages: Entire tech stack & App code
Real-world Example: Google Workspace (Gmail/Docs), Microsoft 365, Dropbox, Slack.

  1. Created a public GitHub repository named cloud-lab1.
